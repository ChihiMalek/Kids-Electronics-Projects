## About

Electronics is not only for experts. Everyone starts somewhere.

This repository is a collection of **simple electronics projects for beginners**.
The goal is to **learn Arduino by building**, understand how each component works, and gain confidence one project at a time.

## Why "Kids"?

Every project is designed to be **as simple as a game**:

| Principle | Description |
|---|---|
| **Few components** | Cheap and easy to find |
| **Commented code** | Every important line is explained |
| **Component tests** | One test per component before the full build |
| **Wiring diagram** | Professional schematic and real photo |
| **Online simulation** | Try the project on Wokwi, without hardware |

No experience needed. Just curiosity.

## Getting Started

**Requirements**
- [Arduino IDE](https://www.arduino.cc/en/software) (free)
- An Arduino Uno board

**Steps**
1. Open a project folder.
2. Read its `README.md` (materials, wiring, explanations).
3. Run the sketches in the `tests` folder, one component at a time.
4. Upload the main sketch.
